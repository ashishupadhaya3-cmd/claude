# RoomKhoj 🏠

A simple room-finder MVP mobile app for Nepal built with **React Native (Expo)** and **Firebase** (Firestore + Storage).

Users can:

1. 📋 Browse room listings
2. 🔍 View listing details
3. 📝 Post a new room
4. 📞 Call the owner directly

No authentication, no backend server — just a clean, working MVP.

## 🚀 Run the App Locally

### Step 1 — Install Node.js and Expo CLI

Install [Node.js (LTS)](https://nodejs.org/) if you don't have it.

```bash
npm install -g expo-cli
```

### Step 2 — Install Project Dependencies

From the project folder:

```bash
npm install
```

### Step 3 — Start the Expo dev server

```bash
npm start
```

This opens the Expo Dev Tools in your browser. Scan the QR code with the **Expo Go** app on Android/iOS to launch the app on your phone, or press `a` for Android emulator / `i` for iOS simulator.

> 💡 Before you set up Firebase, the app will automatically show **dummy data** so you can see the UI immediately.

## 🔥 Firebase Setup Guide

### Step 1 — Create a Firebase project

1. Go to <https://console.firebase.google.com/>
2. Click **Add project**
3. Give it a name (e.g. `roomkhoj`) and finish the wizard

### Step 2 — Add a Web App

1. Inside your project, click the **Web icon** (`</>`)
2. Register the app (nickname `roomkhoj-web`)
3. Copy the `firebaseConfig` object shown

### Step 3 — Paste config into `firebaseConfig.js`

Open `firebaseConfig.js` and replace the placeholder object:

```js
const firebaseConfig = {
  apiKey: 'YOUR_API_KEY',
  authDomain: 'YOUR_PROJECT.firebaseapp.com',
  projectId: 'YOUR_PROJECT_ID',
  storageBucket: 'YOUR_PROJECT.appspot.com',
  messagingSenderId: 'YOUR_SENDER_ID',
  appId: 'YOUR_APP_ID',
};
```

### Step 4 — Enable Cloud Firestore

1. In the Firebase console, go to **Build → Firestore Database**
2. Click **Create database**
3. Start in **test mode** (for MVP). Choose your region.

### Step 5 — Enable Storage

1. Go to **Build → Storage**
2. Click **Get started** and accept default rules (test mode).

### Step 6 — (Dev only) Open rules so you can write

For MVP / local testing only — **not for production**:

**Firestore rules**

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
```

**Storage rules**

```
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /{allPaths=**} {
      allow read, write: if true;
    }
  }
}
```

## 🗂 Firestore Schema

Collection: **`listings`**

| Field       | Type      | Example                          |
| ----------- | --------- | -------------------------------- |
| `id`        | string    | auto-generated by Firestore      |
| `title`     | string    | "2BHK near Thamel"               |
| `price`     | number    | `15000`                          |
| `location`  | string    | "Thamel, Kathmandu"              |
| `roomType`  | string    | "1 room" / "2 room" / "flat"     |
| `amenities` | string[]  | `["WiFi", "Water", "Parking"]`   |
| `phone`     | string    | "9812345678"                     |
| `imageUrl`  | string    | Firebase Storage download URL    |
| `description` | string  | "Spacious, sunny, near bus stop" |
| `createdAt` | timestamp | serverTimestamp()                |

## ✨ Features Implemented

- ✅ Home screen with FlatList + listing cards
- ✅ Pull-to-refresh
- ✅ Loading indicator
- ✅ Empty state ("No listings yet")
- ✅ Detail screen with image carousel + call button
- ✅ Post listing form with:
  - Title / Price / Location / Description
  - Room type selector
  - Amenities checkboxes
  - Phone field
  - Image picker → Firebase Storage upload
- ✅ Direct call via `Linking.openURL('tel:...')`
- ✅ Auto-refresh Home when returning from PostListing
